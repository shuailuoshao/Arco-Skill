# Arco 图片审阅工作室

在 Windows 中双击 **启动审阅.cmd**，浏览器会打开本机页面。再次启动会复用当前服务。
使用工作区 `.venv` 的 Python；第一次缺少 Pillow 时启动器会通过系统代理安装。

## 快速筛选：只判断保留或丢弃

启动器默认打开“快速筛选”，覆盖全库所有版本（含历史及失败稿），不受详细图库的筛选影响。
只看大图：点击 **保留** 或 **丢弃**，保存成功后自动进入下一张。图片未加载或保存失败时不会自动前进。
丢弃只是人评分类，不删除原图。已有评分、备注和修改方向继续保留。

快捷键：**→ / K** 保留、**← / D** 丢弃、**Z** 撤销上一次、**空格** 跳过。
撤销支持本次打开页面后的判断；刷新后通过“保留／丢弃”分组回看、重新选择即可改判。
“待判断”包括尚未选保留或丢弃的作品，即使之前已经填写了评分或修改结论。
当前分组与图片位置保存在本机；“详细审阅”可进入原有评分界面。

## 逐张审阅

图库默认显示 2026-10-03 起归档的图片，按主题批次优先展示最新非失败版。
全部版本均失败的作品仍展示最新失败版，可切换“展开全部版本”或在工作台切换版本。
按归档日期筛选，不按文件修改时间或批次名称推算日期。

点击作品进入工作台：生成图、外部原图和评分同时展示；其他角色、服装参考默认折叠。
点击图片放大，用缩放滑块及滚动查看细节；“版本对比”支持任意同批次版本并排查看。
参考优先展示当次归档副本，详情注明用途、来源、继承范围及调用证据。

总体分和六个分项均为 1–5 分，全部可以留空。任意有效评分、标签、备注或结论保存后即已评。
浏览图片不产生人评；空的修改方向不计入评价。暂缓后也可以继续评价。
画面瑕疵分越高表示画面质量越好、瑕疵越少。

输入后自动保存；“保存后下一张”会等待本机保存成功。保存失败时保留页面和浏览器草稿，
显示错误并提供重试、下载草稿。关闭存在未保存内容的页面会提示。另一窗口更新人评时提示冲突，
重试覆盖前需明确选择；打开有冲突旧草稿的图片时可下载旧草稿核对。

快捷键（不在输入框或对话框内）：**1–5** 总体评分、**0** 清空总体分、**← / →** 上下张。
**Ctrl / ⌘ + Enter** 保存后下一张。续评位置、筛选条件和评分都保存在本机。

## 高分参考分析

默认高分 ≥4、低分 ≤2，门槛可以调整且不得重叠；中间分、未填总分单列。
分析仅沿用左侧**归档起止日期**，不受图库搜索、服装、人评状态或最新版本折叠限制。
全部命中的评分版本参与分析，重点显示对应外部原图。

外部原图以内容 SHA-256 去重，保留别名和全部关联证据；一个原图可以同时出现在高低分组。
生成链沿 `parent_output` 识别，初次生成与最新填过**总体分**的版本分别列出。
初次生成未评分或不在日期范围不推算分数；修订次数不等于独立试验次数。

页面汇总服装及记录中的参考用途，不自动识别画风等视觉特征，也不从作品分数自动判断参考适用性。
导出的 Markdown 含后续视觉分析问题、证据和本机路径，可以交给同一机器上的 Codex 对话继续分析。

## 导出、备份和数据位置

“导出与备份”提供修改清单及分析资料的 Markdown / JSON，以及全部人评 JSON 备份和恢复。
修改清单包括选择局部修改、重新生成或填写修改方向的版本；未写说明仍导出并提示待补充。
所有图片只以本机绝对路径提供，不复制或打包原图。
恢复时先显示新增、冲突、相同和无法匹配条目数量，可保留本机记录或明确用备份覆盖。
无法匹配版本、已更换哈希的版本跳过，整份备份校验成功后才写入数据库。

运行数据位于本目录 `.local/`，已排除 Git：

- `reviews.sqlite3`：独立人评、续评位置；按 output_id 和图片 SHA-256 绑定。
- `thumbnails/`：按实际图片哈希缓存缩略图，仅缓存被浏览的图片。
- `exports/`：每次导出先保存本机副本，再提供浏览器下载，下载被浏览器阻止时仍可在这里找到资料。
- `instance.json`：当前服务地址和进程；`service.log` / `service-error.log`：启动器日志。

应优先用 JSON 备份迁移人评；不要在服务运行时只复制 SQLite 主文件而遗漏 WAL。
软件不写原图、生成记录、作品登记表、user_accepted 或已有机器检查状态。

## 开发和检查

在工作区根目录用 PowerShell 7：

```powershell
& .\.venv\Scripts\python.exe -m pip install --proxy http://127.0.0.1:7897 -r apps\artwork-review\requirements.txt
& .\.venv\Scripts\python.exe -m unittest discover -s apps\artwork-review -p test_review.py -v
& .\.venv\Scripts\python.exe apps\artwork-review\server.py --audit
& .\.venv\Scripts\python.exe apps\artwork-review\server.py --audit --hashes
& .\.venv\Scripts\python.exe apps\artwork-review\server.py --open
```

默认端口为 8931；占用时使用空闲端口。服务只监听 `127.0.0.1`，页面写操作带会话凭证。
页面只能请求已登记图片，不提供任意文件路径读取。`--data-dir` 可指定独立测试数据目录。
启动或点击“刷新归档”读取新增作品，刷新失败时保留最后成功读取的目录。
可点击侧栏“保存并停止本机服务”结束服务；前台运行时也可以按 Ctrl+C。
启动器会复用同版本服务，检测到代码更新时通过本应用接口停止旧服务并重新启动。
